## 🚀 Proyecto principal

### NÓRDICO — Backend de distribuidora de hielo

Microservicio de autenticación y operaciones en producción.

- **Stack:** Java 25 + Spring Boot 3.5 + PostgreSQL 15 + Flyway
- **Seguridad:** JWT HS256, refresh token rotation, BCrypt cost 12, OAuth2 resource server, rate limiting
- **Storage:** AWS SDK v2 / S3-compatible para evidencia fotográfica
- **Realtime:** WebSocket nativo
- **Docs:** OpenAPI 3.1 / Swagger
- **Calidad:** TDD estricto con JUnit 5, Mockito, @WebMvcTest, Security IT, H2 en tests
- **Deploy:** Docker multi-stage, Render Blueprint
- **Repo:** [Nordico-proyectos/nordico-ms](https://github.com/Nordico-proyectos/nordico-ms)
